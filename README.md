## 📌 О проекте

Дипломный проект: система предотвращения утечек данных (DLP), ориентированная на контроль финансовой информации (номера банковских карт, IBAN, CVV, API-ключи). 

Система перехватывает и анализирует трафик между пользователем (или AI-агентом) и внешними AI-сервисами (например, `chat.deepseek.com`, `api.openai.com`), а также контролирует буфер обмена.

**Ключевые отличия:**
*   **Фокус на AI:** контроль не только браузера, но и MCP-вызовов (Model Context Protocol).
*   **Финансовый сектор:** встроенные алгоритмы валидации (Луна для карт, MOD-97 для IBAN).
*   **Действия:** блокировка запроса, маскировка данных или логирование инцидента.
*   **Офлайн-режим:** Java-агент копит инциденты локально (SQLite) при потере связи с сервером.

## 🏗 Архитектура

Репозиторий представляет собой монорепозиторий, разделенный на три основных компонента:

*   **`agent/`** — Java-агент (Netty, MITM-прокси, SQLite). Устанавливается на ПК пользователя. Перехватывает HTTP/HTTPS, Clipboard и MCP-трафик.
*   **`server/`** — Backend (Spring Boot 3, PostgreSQL, MinIO). Принимает инциденты, хранит политики, управляет карантином.
*   **`web/`** — Веб-панель администратора (Vue.js 3). Дашборд, журнал событий, управление политиками.
*   **`infra/`** — Docker Compose для запуска PostgreSQL, PgBouncer и MinIO.
*   **`docs/`** — Диаграммы, документация и материалы диплома.

## 📋 План разработки

Проект разрабатывается поэтапно:
1.  **Агент-прототип:** перехват HTTP, поиск карт, сохранение в SQLite.
2.  **HTTPS + Маскировка:** MITM-прокси, подмена данных в трафике.
3.  **Минимальный сервер:** прием инцидентов, выдача политик.
4.  **Clipboard-модуль:** перехват буфера обмена.
5.  **PostgreSQL:** переход с SQLite на реальную БД.
6.  **MCP-модуль:** анализ вызовов инструментов.
7.  **Веб-панель:** интерфейс администратора.
